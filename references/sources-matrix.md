# 七类数据源检索矩阵

> P1 采集阶段按本矩阵逐类执行。每类给出：首选工具、检索关键字模板、双源/交叉规则、产出字段。降级铁律见文尾。

## 1 · 工商与治理

| 项 | 内容 |
|---|---|
| 首选 | 企查查 `get_company_registration_info` / `get_shareholder_info` / `get_company_profile`；天眼查 `get_company_basic_profile` |
| 补充 | 变更记录 `get_change_records`（法人/注册资本/股东变更历史）、分支机构 `get_branches`、对外投资 `get_external_investments`、年报 `get_annual_reports`、实控人与受益所有人 `get_actual_controller` / `get_beneficial_owners`、主要人员 `get_key_personnel` |
| 关键字 | `{公司全称}`；变更项逐条拉取 |
| 双源规则 | 法人、注册资本、股东、登记状态：企查查 × 天眼查双源核对，不一致时注明两平台各显示什么、以最新登记为准 |
| 产出 | 表1-1 全部字段、表1-2 股东明细、1.4 资质标签、法人/资本变更时间线 |

## 2 · 融资动态

| 项 | 内容 |
|---|---|
| 首选 | 企查查融资事件字段 + `WebSearch` |
| 关键字模板 | `{公司名} 融资`；`{公司名} {投资方}`；`{赛道} 融资周报 {年月}`；`{城市} "{产业政策名}" 获投`（如深圳"20+8"周度获投汇总）；`{赛道} 产业洞察`（如上海国投先导系列） |
| 交叉规则 | 轮次与投资方至少两个来源互证（融资周报 × 产业洞察 × 媒体通稿）；金额未披露如实记录 |
| 产出 | 表2-1 轮次明细、资金用途、对应工商变化（与第 1 类注册资本变更对照） |

## 3 · 团队线索

| 项 | 内容 |
|---|---|
| 首选 | `WebSearch`（无专用 MCP） |
| 关键字模板 | `{姓名} {公司名}`；`{姓名} {疑似前雇主}`；`{姓名} 论文/专利/演讲`；`{公司名} 招聘`（Boss直聘/猎聘快照可反推团队规模与技术栈）；`{姓名} {高校}` |
| 分级规则 | 同名人士一律 `unverified`；仅当多来源指向同一履历链（如论文作者单位+会议职务+媒体报道互证）才可升 `corroborated`，仍须标注"同一性待核实" |
| 产出 | 表1-3 团队线索、竞业限制与职务成果核查项 |

## 4 · 技术与知识产权

| 项 | 内容 |
|---|---|
| 首选 | 天眼查 `search_patents` / `search_trademarks` / `get_company_capabilities`（软著/备案）；企查查知识产权字段 |
| 补充 | `WebSearch`：`{公司名} 专利`、`{公司名} 官网`、`{公司名} site:mp.weixin.qq.com`、ICP 备案查询类站点 |
| 交叉规则 | 专利区分公司名下与创始人个人名下（发明人检索 `{姓名}` 单独跑一遍）；审查中 ≠ 已授权 |
| 产出 | 3.3 知识产权现状（含"未发现"的否定性结论+检索日期） |

## 5 · 行业与市场

| 项 | 内容 |
|---|---|
| 首选 | `WebSearch` + `WebFetch`（市场规模、竞争格局、政策）；`ima-mcp` search_knowledge（券商研报）；`neodata-financial-search`（上市公司对标财务/市值） |
| 关键字模板 | `{赛道} 市场规模 {年份}`；`{赛道} 竞争格局`；`{赛道} 政策 {年份}`；`{对标上市公司} {年份} 年报 营收` |
| 双口径规则 | 市场规模至少两个机构口径并列；口径差异大时（如窄口径软件/服务 vs 宽口径全产业链）在表注解释 |
| 产出 | 表4-1 多口径数据、表4-2 竞争格局、4.3 政策与风险信号 |

## 6 · 司法与合规

| 项 | 内容 |
|---|---|

## 7 · 区域政策归类

| 项 | 内容 |

## 降级铁律

1. MCP 连接器（企查查/天眼查）不可用 → `WebSearch` 检索"爱企查/天眼查/企查查 + 公司名"的公开页面快照替代，报告中标注"数据源受限（MCP 不可用，使用公开页快照）"。
2. 关键项单源孤立 → 继续检索至双源或明确标注"单一来源，待核实"；仍无法交叉 → 降级为 `unverified`。
3. 查不到 = 查不到。任何情况下不得编造数据、来源、日期。
