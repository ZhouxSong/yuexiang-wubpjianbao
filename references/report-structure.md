# 公司简报五章结构规范（无 BP 场景）

> 本文档是 P3 撰写阶段的骨架蓝本。章节顺序、表格清单、caption 规范均为强制项；各节内容随采集结果填充，查不到的信息显式写"未公开披露"并进入 5.3 清单，不得留白或编造。

## 0 · 开篇声明（正文第一段，强制模板）

```
本简报基于公开渠道信息整理（查询日期 YYYY年M月D日）。需要特别说明：该公司{无官方网站/未公开商业计划书（BP）及任何产品资料——按实际情况描述信息透明度}，本简报信息主要来源于：{渠道列举：爱企查/天眼查/企查查等工商登记与股权穿透数据、XX产业洞察/投融资周报、行业研究机构（XX、XX）数据、公开新闻报道等}。文中严格区分"事实"与"推测"，凡无法交叉验证的信息均已明确标注，并在第五章给出尽调核实建议清单。
```

要求：①必须写查询日期；②渠道列举必须与实际使用的一致（与 5.4 来源清单呼应）；③"事实与推测分离"表述必须出现。

## 第一章 公司概况

| 节 | 内容 | 强制要素 |
|---|---|---|
| 1.1 工商基本信息 | 一段定位描述 + 工商表 | 表1-1：公司名称/统一社会信用代码/法定代表人/成立日期/注册资本/企业类型/登记状态/注册地址/所属行业/人员规模/官网与联系方式/登记机关；表后接经营范围全文 + 逐条解读段（指出与业务方向相关的条目，推测须标注） |
| 1.2 股东结构与实际控制关系 | 股东表 + 控制权测算段 | 表1-2：股东名称/持股比例/备注（一层直接持股；持股平台须列合伙人构成）；控制权测算写穿透计算过程（如"平台A 30.38%×99.8% + 平台B 28.21%×49.8% ≈ 44.4%"）；外部投资方持股比例合计与稀释幅度 |
| 1.3 核心团队与背景线索 | 团队线索表 + 规模推断段 | 表1-3：姓名/角色/背景线索；所有线索标注来源与"待核实"；同名人士线索写明证据链（论文、职务记录）并注明"是否同一人未见直接证据"；衍生竞业限制/IP 边界核查提示 |
| 1.4 资质与标签 | 项目符号列表 | 融资阶段标签、企业规模标签、产业归类（如深圳"20+8"集群）、高企/科技型中小企业等资质（无则注明原因，如成立时间过短） |

## 第二章 融资与经营状况

| 节 | 内容 | 强制要素 |
|---|---|---|
| 2.1 融资情况 | 每轮一张表 + 时点特征段 | 表2-1：轮次/披露时间/融资金额（未披露如实写）/投资方/资金用途/对应工商变化（注册资本变动）；时点特征分析（设立到首轮的间隔、投资方结构含义） |
| 2.2 投资方背景 | 投资方表 | 表2-2：投资方/背景说明（管理规模、阶段偏好、代表案例、本基金 LP 结构）；身份不明的主体（尤其境外）单独提示并列入尽调问题 |
| 2.3 经营与财务线索 | 可查线索列表 | 有则写：年报数据、参保人数、招聘动态、客户/订单线索、税务评级、进出口信用；无则逐项写"未公开披露"，并说明信息缺口含义。**禁止编造财务数字** |

> 无融资记录的标的：第二章改为"股权变动与资金线索"，如实描述无公开融资记录，从注册资本实缴、股东出资、政府资助/园区扶持等侧面描述。

## 第三章 业务方向与技术逻辑

| 节 | 内容 | 强制要素 |
|---|---|---|
| 3.1 业务定位 | 引用权威来源原文 | 引最权威的一句业务概括（产业洞察/融资通稿/官网），注明来源与期号；对专业术语做一段科普性解释 |
| 3.2 技术路线推测 | 项目符号列表 | 标题必须带"（未经公司确认）"；分算法/产品侧、实验/交付侧、商业模式三条线推测；每条末尾标"（推测）"；段末加免责句"以上均为行业常识映射下的推测，不构成对公司实际技术路线的认定" |
| 3.3 知识产权与资产状况 | 一段 | 专利/商标/软著/ICP 备案检索结果与截止日期；空白属正常时说明原因，并指出"无法通过公开渠道评估技术积累"→导入尽调 |

## 第四章 行业与市场分析

| 节 | 内容 | 强制要素 |
|---|---|---|
| 4.1 市场规模与增长 | 多口径数据表 + 阶段判断段 | 表4-1：口径/数据/来源与时间（**至少两个机构口径并列**，口径差异大时表注说明，如"两个口径相差一个数量级，分别对应窄口径与宽口径"）；阶段判断段写行业当前所处阶段与对新进入者的含义 |
| 4.2 竞争格局 | 玩家表 + 解读段 | 表4-2：企业/总部/核心方向/现状（截至YYYY年M月），覆盖 6-10 家代表玩家；解读段写头部集中度、标的公司的合理定位、赛道与资本偏好契合度 |
| 4.3 政策环境与行业风险信号 | 项目符号列表 | 政策利好（逐条注明发布时间与发文机关）+ 风险信号（逐条注明事实来源，如盈利预警、团队解散、临床通过率数据）+ 对标的公司的含义 |

## 第五章 其他重要信息与风险提示

| 节 | 内容 | 强制要素 |
|---|---|---|
| 5.1 同名/近似名公司辨析 | 辨析表（**必备，不可省略**） | 表5-1：主体/辨析说明（成立日期、法人、方向、与本项目无已知关联的结论依据）；即使 P0 未发现同名主体，也要写"经检索未发现同名/近似名主体（检索范围：天眼查全国企业库+网络检索，日期）" |
| 5.2 风险提示 | 项目符号列表 | 至少覆盖：极早期/信息不透明/团队核实风险/投资方身份风险/行业风险/注册地与实际办公地核实；每条写明风险依据 |
| 5.3 尽调核实建议清单 | 项目符号列表 | 按 团队/技术/融资/规划/合规 五类组织，每条可执行（如"核实 X 是否曾任 Y 职务、离职时间与竞业安排"）；P2 标记为 `unverified`/`gap` 的条目必须全部出现在此 |
| 5.4 主要信息来源清单 | 来源表 | 表5-2：类别/来源/时间/支撑内容；覆盖报告全部引用；每个来源写到可定位粒度（平台名+期号/日期） |

## 小结（末段，强制）

一段式客观复述：主体画像（设立时间、方向、轮次、投资方、股权结构要点）→ 行业位置（赛道热度与头部格局）→ 信息透明度评价 → 尽调重点（优先核实什么、再决定是否进入深度尽调）。**不出现"建议投资/不建议投资"类结论**。

## 表格与 caption 规范

- 每张表必须有 caption，格式：`表X-Y {标题}（来源：{平台/机构列举}，查询日期/时间 YYYY-MM）`，9 pt 灰色（#555555）居中，置于表下方。
- 表格字体 8.5-9.5 pt（内容密度高时 8.5），表头白字加粗。
- 表格列数 ≤5；长文本列（如"背景说明"）放最后。

## 篇幅基准

实战案例约 10-15 页。信息采集充分时不低于 8 页正文（不含表格不足则说明采集不充分，回到 P1 补检索）。
